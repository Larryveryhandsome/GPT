# 水牛哞哞怪 MooMoo Monster｜官網與尋哞手帳

此目錄是可直接託管的靜態網站，不需要安裝前端套件。

## 本機使用

需要 Node.js 20 以上。在此目錄執行 `npm start`，開啟 `http://127.0.0.1:4175/`。請使用 HTTP 本機預覽或 HTTPS 網址；不要直接雙擊 HTML，瀏覽器會阻擋 JavaScript 模組。

`npm test` 執行遊戲規則測試。完整瀏覽器 QA 證據在交付包的 `06-qa/`。

## 已實作

- 繁體中文官方品牌首頁、角色／世界觀、正式社群入口。
- 本機 MOO ID 暱稱與隨機識別碼，資料保存在 localStorage。
- 台灣日曆每日一次 +5、三篇線上故事各一次 +10、尋哞圖鑑。
- 有格式檢查與確認步驟的匯入、匯出、清除與改名。
- 鍵盤可操作對話窗、錯誤訊息、儲存不可用提示與損壞資料保留。
- 響應式版面；首次成功載入後，網站主要頁面和本機手帳可離線使用。
- MOO Station 與 Genesis 1000 的真實籌備狀態、合作準備清單。

## 公開能力邊界

本機 MOO ID 不是雲端會員、身分驗證、正式實體活動憑證或核銷系統。沒有跨裝置自動同步；可手動匯出與匯入。清除瀏覽器資料可能失去手帳。哞力可由裝置擁有者修改，因此不能用於實體資格判定。

實體據點沒有確認名單；Genesis 1000 是規劃數量，沒有發行、庫存或領取承諾。正式會員、QR 防重放驗證、編號綁定與後台需要另行接上伺服器與營運資料。

## 維護

- 首頁：`index.html`；排版：`style.css`；互動：`app.js`；可測試規則：`state.js`。
- 發布可放在任何子目錄，內部資源使用相對路徑。
- 變更部署網址時，同步修改 HTML 的 canonical/og:url 及公開分享圖網址。
- 更新離線資源後，更新 `sw.js` 的 CACHE 版本字串。Service Worker 僅清理本站 `moomoo-verse-` 前綴的舊快取。
- 角色資產只使用依官方帳號截圖製作的 V2。平面奶油角 V1 已停用，不得混用。
- 交付包中的帳號密碼或私人工作檔不在此來源目錄中，也不得加入。

## 部署隔離

既有 `Larryveryhandsome/GPT` 的 Pages 根目錄是另一份講義。本站部署在該來源分支的 `moomoo/` 子目錄；不可替換原根目錄或任意切換 Pages 來源。
